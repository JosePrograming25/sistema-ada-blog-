Parche 1.2.1 30 de mayo de 2026

v1.2.1 — Compatibilidad con Windows 7, 8 y 8.1

El instalador ahora funciona en Windows 7, 8 y 8.1 (32 y 64 bits). Ya no se requiere tener Node.js instalado en el sistema y la aplicación solicita permisos de administrador automáticamente.

¿Qué hay de nuevo?

Compatibilidad con Windows 7, 8 y 8.1

El instalador de Sistema Ada ahora funciona en equipos con Windows 7 SP1, Windows 8 y Windows 8.1, tanto en versiones de 32 bits como 64 bits.

Anteriormente la aplicación solo corría correctamente en Windows 10 y 11. A partir de esta versión, cualquier equipo con Windows 7 o superior puede instalar y usar el sistema sin problemas.

Ya no requiere Node.js instalado

Uno de los cambios más importantes de esta versión: el sistema ya no necesita que Node.js esté instalado en el equipo.

En versiones anteriores, si el PC no tenía Node.js, la aplicación abría una ventana en blanco sin mostrar ningún error. Ahora todo lo necesario para ejecutar el servidor interno viene incluido dentro del propio instalador.

Permisos de administrador automáticos

La aplicación ahora solicita permisos de administrador automáticamente al abrirse, sin que el usuario tenga que hacer nada. Esto resuelve el problema que tenían algunos equipos con Windows 8 donde la app abría en blanco hasta que se ejecutaba manualmente como administrador.

¿Algo no funciona?

Si al instalar o usar el sistema en un equipo antiguo encuentras algún problema, por favor repórtalo usando el formulario de la web. Tu reporte ayuda a mejorar el sistema para todos.

¿Cómo actualizo?

Si tienes el sistema instalado en Windows 10 u 11, debería aparecer una notificación automática de actualización. Si no aparece, cierra y vuelve a abrir la aplicación.

Para equipos con Windows 7, 8 o 8.1 descarga el instalador directamente y vuelve a instalarlo.
